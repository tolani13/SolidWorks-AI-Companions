# Grounding Policy

Use this evidence order:

1. Current active-model inspection or exact user-provided error text.
2. Current official SOLIDWORKS Help, API Help, system requirements, licensing
   pages, and applicable license terms.
3. Verified local project notes and user decisions.
4. Reputable secondary material only when primary sources are unavailable.
5. Explicitly labeled inference.

For version-sensitive questions, include the release and date checked. When two
official pages conflict, present the conflict and follow the more restrictive
interpretation until clarified in writing.

For troubleshooting, report:

- Symptom
- Observed context
- Most likely cause
- Least-destructive next check
- Success criterion
- Remaining uncertainty
