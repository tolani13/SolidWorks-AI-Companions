# SOLIDWORKS Connected Notes

Verified against official SOLIDWORKS documentation on 2026-07-25:

- SOLIDWORKS Connected uses named-user licensing and can be installed on
  multiple devices for the same named user.
- Maker-native `.sldprt`, `.sldasm`, and `.slddrw` files are digitally
  watermarked and cannot be opened by commercial or academic SOLIDWORKS.
- Neutral exports such as STEP, IGES, STL, and DXF remain shareable but do not
  preserve the complete native parametric model.
- Maker does not support third-party add-ins.
- SOLIDWORKS Connected supports macros and most standard SOLIDWORKS APIs.
- Platform storage changes some open/save APIs, and the PDM Professional API
  does not work with SOLIDWORKS Connected.
- Offline use is limited to 30 consecutive days.
